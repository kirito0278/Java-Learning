INTRODUCTION:
--Java was developed at Sun Microsystems in 1991 by James Gosling and his team. It was initially called Oak, but the name was later changed to Java. Java was officially released in 1995. It was designed with the goal of platform independence, commonly expressed as "Write Once, Run Anywhere." Java source code is compiled into bytecode, which is executed by the Java Virtual Machine (JVM). In 2010, Oracle acquired Sun Microsystems and took over Java's development.

JAVA:
--Java is a high-level, object-oriented, statically typed programming language used to build applications, backend systems, APIs, enterprise software, and more.

Java is famous for:
"Write Once, Run Anywhere (WORA)"
This is possible because Java source code is compiled into bytecode, which is executed by a JVM available for the target platform.
--Java bytecode is platform-independent, while the JVM is platform-specific.


JDK:
JDK = Java Development Kit
Used to develop Java applications.
Contains development tools such as:
javac → Java compiler
-- Main purpose: Develop Java programs

JRE
JRE = Java Runtime Environment
Provides the environment required to run Java applications.
Conceptually:
JRE = JVM + runtime libraries
--Main purpose: Run Java programs

JVM
JVM = Java Virtual Machine
A runtime engine that executes Java bytecode.

Main responsibilities include:
Loading classes
Executing bytecode
Memory management
Garbage collection
JIT compilation
--Main purpose: Execute Java bytecode





.java
A .java file contains Java source code written by the programmer.
Example: Main.java

Compilation
Java source code is compiled using: javac
Example: javac Main.java
This produces: Main.class

.class
A .class file contains Java bytecode.
.java
  ↓ javac
.class

Bytecode
Bytecode is the intermediate code generated by the Java compiler.
It is stored inside .class files and is executed by the JVM.
Java Source
    ↓
Bytecode
    ↓
JVM
    ↓
Execution

How Java Runs
Main.java
   ↓
javac
   ↓
Main.class
   ↓
Bytecode
   ↓
JVM
   ↓
Machine-level execution
   ↓
CPU
   ↓
Output




JShell:
--JShell (Java Shell) is an interactive command-line tool provided with the JDK that allows us to write, execute, and test Java code interactively without creating a complete Java source file and main() method for every small experiment.

Purpose:
JShell is mainly used for:
Learning Java
Testing code
Experimenting with Java features
Testing expressions
Testing methods
Quick debugging/experimentation

Starting JShell:
Open Command Prompt/Terminal and type:
jshell
Example
jshell> 10 + 20
$1 ==> 30
jshell> System.out.println("Hello Java");
Hello Java
Variables
int age = 20;
String name = "Parth";
Methods
int add(int a, int b) {
    return a + b;
}
Then:
add(10, 20)

Important JShell Commands:
Command	Purpose
/help	Shows help
/vars	Shows variables
/methods	Shows methods
/types	Shows classes/types
/list	Shows entered code
/history	Shows command history
/exit	Exits JShell
